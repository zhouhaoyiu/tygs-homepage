# 太原供水城北营销服务页

React 服务目录，提供服务热线拨号、营业网点、报修联系、可搜索的用水问答。页面不收集居民资料，不伪装在线受理或发布实时停水信息。

运行 `pnpm install`、`pnpm dev`；发布前运行 `pnpm build`。静态服务器需将页面路由回退到 index.html。

服务号码沿用原项目。网点信息来源：太原本地宝《太原供水集团营业网点》，资料日期 2025-10-22：https://ty.bendibao.com/news/2020919/46433.shtm 。页面保留资料日期与来源链接，营业时间未编造。实际发布前由业务人员核对网点与受理范围。

标志来自同一账号的 tygs 项目。
